# 路线图

> Linger（灵犀）是一个「长期陪伴」向的 AI 人格引擎：不是给一个助手换层皮，
> 而是让角色**记住你、对你有情绪、关系会变**，并且这个角色是**可生产、可交换**的。
>
> 这份文档是**对外版本**：只讲「做到哪、能做什么、接下来做什么」。
> 内部验收记录与协作过程不在这里。

## 二、现在能做什么

**聊天**：选人格、选场景、开聊。回复是流式的，前面能看到「回忆 → 组织」的思考事件和情绪变化。

**人格从哪来**（四个入口，产出的卡结构一致）：

1. **模板**：内置两个人格，开箱即用
2. **一句话生成**：说一句「一个嘴硬心软的退役剑客」，它写完整张卡
3. **聊天记录蒸馏**：给一段真实对话，提取说话方式
4. **五步向导**：一项一项自己填

**记住你**：对话里的事会沉淀成记忆，分三层（事实 / 印象 / 关系），可以查看、修正、删除。
她还会写**第一人称日记**，一天一篇。

**关系会变**：关系等级不是开关，靠「深度倾诉、自我披露、共鸣」累积；
情绪有惯性、有变化速率限制（不会一秒从难过变狂喜）。

**陪伴档案**：她对你的判断（处在人生哪个阶段、你俩是什么关系、当下需要什么、有没有风险信号）
全部摊开给你看，**判断错了可以手动改**。

**语音**：麦克风录音 → 转文字进输入框（**不自动发送**）；回复可以播放。

**人格市场**：逛、上架、审核、安装、下架。未登录也能只读浏览。

**成本看板**：今日与近 7 日的 token、失败率、按 provider 拆分。

**换模型**：右上「模型」里填一个 OpenAI 兼容的 key，点保存即生效，不用改环境变量、不用重启。

## 三、几条不妥协的设计红线

这些不是功能，是「宁可少做也不将就」的选择。写在这里，因为它们解释了代码里一些看起来多余的判断。

1. **`cloned`（蒸馏产物）不许上架。**
   它复刻的是一个**真实的人**的说话方式，那个人没有同意被全世界使用。后端拒绝，前端连入口都不显示。

2. **不知道的单价显示「未知」，绝不显示 0。**
   0 会被读成「这次调用免费」，而真相是「我们不知道它花了多少」。
   把「不知道」渲染成「免费」，是比缺失更糟的谎言。

3. **模型失败必须静默降级，不能拖慢主链路。**
   事件评估是旁路，模型挂了就退回规则，不抛异常、不让这一轮对话失败，只留一条 `eval_source: rule`。

4. **未登录不弹登录墙。**
   市场可以裸逛。只有写操作（上架 / 安装 / 审核）才要求登录。

5. **审核权不配 = 没人能审。**
   宁可没人批，也不能谁都能批；作者不能审自己。

6. **模型只加敏感度，不是否决权。**
   模型的判断与规则「取或」——一次抽风不该让关系倒退。

## 四、接下来

按价值排序的候选，不是承诺：

| 方向 | 现状 |
|---|---|
| 日记生成的前端入口 | 接口有，界面缺一个按钮 |
| 生产部署清单 | 需要显式配置 `LINGER_AUTH_SECRET`；密码哈希依赖 OpenSSL 的 scrypt |
| 真实模型的效果验收 | 目前全链路用 mock 验证「链路通不通」，不代表「她说得好不好」 |
| 记忆与日记的完整搬移 | 认领账号时记忆是真搬移，日记目前是复制（缺少删除接口） |
| 附件式交付 / 直接下载 | 便于把人格卡导出成文件交换，现在只有在线市场 |

## 五、怎么验证它真的能跑

```bash
pip install -e ".[dev]"

python -m pytest        # 1022 passed / 9 skipped
python -m evals.run     # 12 条人格评测（她像不像她 / 记不记得住 / 有没有越界）
```

评测是独立的一层，回答的是另一个问题：
单测问「代码对不对」，评测问「味道对不对」。改 prompt、换模型、调温度之后先跑它——
因为它抓的是那种「1000 个测试全绿，但她变成了客服腔」的退化。

想手工试，起服务后打开 <http://127.0.0.1:8000>；界面里有什么、每条产品语义怎么解释，见 README。
